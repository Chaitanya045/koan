**Koan 0.0.2 (Alpha).** Agents can now attach files you give them, the two-finger swipe between Spaces follows your fingers, and Koan shows its own version. It also has a new app icon and fixes from the first round of testing.

> [!WARNING]
> **This is an alpha.** It's for early testers. Expect rough edges, and back up anything you can't lose.
> - Settings and profile formats may change between alpha versions.
> - Security fixes from Chromium are applied on a best-effort basis, not on Chrome's schedule.
> - There's no automatic updater yet: install new versions by hand from this page.
> - The known issues are listed below.

## Download

**@DMG@**: macOS on Apple Silicon (M1 and later). Intel Macs aren't supported.

The SHA-256 checksum is in the `.sha256` file next to it:

```
@SHA256@  @DMG@
```

### Installing

1. Quit Koan if it's running. Open the DMG and drag **Koan** to **Applications**, replacing the old copy.
2. Koan isn't signed with an Apple Developer ID yet, so macOS blocks it the first time it opens: *"Apple could not verify 'Koan' is free of malware"*. Allow it once, either way:
   - **Terminal:** `xattr -dr com.apple.quarantine /Applications/Koan.app`
   - **Or:** click **Done**, open **System Settings → Privacy & Security**, and click **Open Anyway** next to the message about Koan.
3. macOS asks for your login password once, so that Koan can use its **"Koan Safe Storage"** key in your keychain. Click **Always Allow**. Expect this prompt once after each update until Koan is signed with a Developer ID.

## What's new in 0.0.2

### Agents
- **Agents can attach files.** When a page asks for a file, an agent answers the page's own file chooser with `koan upload <tab> <file>`, or `koan act <tab> upload @ref <file>` to click the button and attach in one step. This works for plain file inputs, styled buttons and drop zones. The agent can attach files only in tabs it drives, never while you've taken the tab over, and never from Koan's profile, your keychains, or ssh and cloud credential folders. A pill shows what it attached ([#420](https://github.com/koan-browser/koan/issues/420)).
- **Agent Spaces go away with their tasks.** When an agent ends a task or disconnects, the Space Koan made for it closes. Tabs of yours in that Space stay open.
- **A blank tab an agent opens stays in its own container.** With **Your logins** off, a new blank tab an agent opened (Playwright and Puppeteer start every page that way) used your logins and the pages after it did too. It now stays in the agent's own container, like the agent's other tabs.
- **An agent's scroll no longer pauses its own tab.** Before, Koan took the agent's own scrolling for yours, so the agent's next step waited for you.
- **Your new tabs stay yours.** A tab you open while you're looking at an agent's tab (⌘T, the address bar, a bookmark) is no longer treated as the agent's, so it stays open when the agent ends its task.
- **`koan`** reports a pairing that Koan has forgotten only once.

### Browsing
- **Swiping between Spaces follows your fingers.** Fingers moving right to left bring in the Space on the right; left to right, the one on the left. The sidebar moves with your fingers whatever your natural scrolling setting is. Past the last Space the swipe offers a new Space, and past the first it opens the Library.
- **Settings:** switches show clearly when they're on, and unselected radio buttons are visible in dark mode ([#419](https://github.com/koan-browser/koan/issues/419)).
- **⌘L** keeps its floating card when you switch to another window and back.

### The app
- **Koan's own version.** About Koan and `chrome://version` show Koan's version next to Chromium's: `0.0.2 (Alpha) · Chromium 158.0.8127.18`.
- **A new icon:** the K-Stone mark, in the Dock, About Koan and Settings.
- Koan now lives at [github.com/koan-browser/koan](https://github.com/koan-browser/koan). Old links redirect.

## Known issues

- Idle CPU with many tabs open is higher than it should be.
- [#418](https://github.com/koan-browser/koan/issues/418): Library → History doesn't scroll.
- [#434](https://github.com/koan-browser/koan/issues/434): agents can attach files through file inputs, but not through pages that use the newer file picker (`showOpenFilePicker`). Those still wait for you.
- Folders: a pinned tab can sit above folders, and a folder tab that's closed and reopened doesn't go back into its folder.
- Protected video (Widevine) isn't signed yet, so some streaming sites may refuse to play.
- macOS asks for your keychain password once after each update, as described under **Installing**.

## Build

- Built from the tag `v0.0.2-alpha.1` on `develop`, on Chromium 158.0.8127.18. It's an official (ThinLTO + PGO) arm64 build, made on the maintainer's Mac and signed ad hoc. GitHub's hosted runners can't build that configuration yet (docs/RELEASING.md, "Official builds").
