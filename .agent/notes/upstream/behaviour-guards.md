# Behaviour guards: what Koan relies on, and what fails when it changes

Date: 2026-11-07, pin 158.0.8127.2. #183, rules 3 and 6 of "Upgrade-safe code"
in `.agent/notes/agent-brief.md`.

A rebase can compile and still break Koan: a notification arrives in another
order, a view is in another state, a CHECK that held stops holding. Each hook
row in `docs/REBASE.md` ("After every rebase, re-audit the hooks") names the
upstream **behaviour** its hook assumes. This lists, for every row, which test
fails if that behaviour changes. It is the checklist for the rehearsal runbook
(docs/REBASE.md, "Rehearsing the next milestone") and where a new guard goes.

**Read this first: most guards are Linux e2e checks.** `scripts/e2e/*.mjs`
need a Linux build (headless Ozone), and Linux builds are disabled since
2026-11-03. Until a check is ported to the Mac drivers (`scripts/mac/`: the
`vtabs.sh` modes, the `steps/*.md` lists) or becomes a unit test in `src/`,
it documents the behaviour but is not run. The last column says which are
runnable now.

Status: **guarded** = a test would clearly fail when the behaviour changes;
**partly** = covered indirectly or only one half; **none** = nothing found.
Found by reading the tests (check titles in quotes), not by running them.

## Totals

Hook table, 53 rows: guarded 31, partly 12, none 10. Runnable on the Mac now:
7; Linux e2e only: 36; no guard: 10.
Issue #183's three examples: guarded 2, partly 1.

## The gaps, by what to add

* **No guard at all (10 rows)**, mostly macOS-only code that Linux e2e could
  never reach: the main menu, Profiles menu and Dock menu hooks, Space
  shortcuts running before Chrome's menu on a Mac, Esc no longer being Stop,
  the Library's closed-tabs source, caption buttons, the traffic lights' row,
  the new-tab button's action swap, and tab rows snapping into a Space.
  Each wants one Mac step (`scripts/mac/steps/`) or, where the logic is pure
  (the menu-key table), a unit test next to `koan_shortcut_table_unittest.cc`.
* **Linux e2e only (36 rows):** port the checks that carry a row to a Mac
  driver, or accept that after a milestone bump nothing runs them. Start with
  the rows whose hook is in the biggest patches (patch-audit.md A1, A2, A7):
  tabs on the right, the sidebar width and drag, the state controller.
* **kEnded order (#176):** only the Mac loop's pin-reversal step guards it,
  and the crash was intermittent: a clean run is weak evidence. A unit test
  with a fake `BrowserAnimationController` listener that starts a motion in
  `kEnded` would make it deterministic (patch-audit.md A8).

## Adding a guard

A hook that relies on behaviour gets, in the same PR: the test that fails if
the behaviour changes, and its name in the REBASE row ("Assumption to
re-check"). Prefer a unit test; then a Mac step or `scripts/mac` driver check;
a Linux e2e check only as a second line. `scripts/ci/patch_report.py` fails a
new patch without a row; the row is where the guard is named.
