# Mac steps: `koan autofill`, and the agent never reads what it fills (design sections 4.5 and 7.0)

For the Mac loop and the hands-on tester. DCHECK build, a fresh test profile, Agent ready on. The scripted part is
`scripts/mac/suite.sh --only agent_autofill` (someone presses Allow when it pairs and when koan-relay starts); its test
data (an address, Visa's test card 4111…1111, a login for the fixture server) is made in the test profile through
chrome://settings and never touches the user's profile. The rest is by hand, with `koan` from
`Koan.app/Contents/Resources/bin/` paired as "koan suite", on local fixture pages (`python3 -m http.server` serving the
forms in `scripts/e2e/agent_autofill.mjs`) or on a test site of your own. Use test data only.
